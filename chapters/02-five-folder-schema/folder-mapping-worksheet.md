# Folder-mapping worksheet

Use this when you're migrating a pile of existing notes into the five-folder schema (see Chapter 2). For each note in your sample, decide which single folder it belongs in. If a note seems to fit two folders, pick one; ambiguous notes that have two homes always end up in neither.

| Folder | What goes here | What does NOT go here |
|---|---|---|
| `_inbox/` | Quick captures you haven't classified yet. Anything you'll process within 7 days. | Project notes you've already routed. Reference material. |
| `projects/<name>/` | Active project work. README + decisions.md + notes.md per project. | Dormant projects (move to `_archive/`). One-off captures. |
| `daily/<date>.md` | Standups, meeting notes, scratch thinking, end-of-day brain-dumps. ISO-dated. | Long-form project notes (those go in `projects/`). |
| `people/<name>/` | Profile, meetings folder, open asks for each recurring contact. | One-off contacts you'll never see again. |
| `_archive/` | Dormant projects, processed daily notes from prior periods, anything moved out of active use. | New material (start in `_inbox/`). |
